# PRD: 책 속 음악 묘사 기반 AI 음악 생성 서비스

## 1. 제품 개요

### 제품명
가칭: **LitSound**

### 한 줄 설명
사용자가 책 속에 등장하는 음악 묘사 문장을 입력하면, 책의 분위기와 문장 속 음악적 단서를 분석해 실제로 재생 가능한 음악을 생성해주는 서비스.

### 배경
소설이나 에세이를 읽다 보면 음악, 노래, 선율, 악기, 분위기, 가사에 대한 묘사가 자세히 등장한다. 하지만 독자는 그 음악이 실제로 어떤 소리였을지 상상에만 의존해야 한다. 이 서비스는 문학적 묘사를 음악 생성 프롬프트로 변환해, 독자가 책의 장면을 더 몰입감 있게 경험하도록 돕는다.

## 2. 목표

### 제품 목표
- 책 제목과 작가 정보를 바탕으로 작품의 전반적 정서, 시대감, 장르적 분위기를 추론한다.
- 사용자가 입력한 음악 묘사 텍스트에서 음악 스타일과 가사 요소를 분리한다.
- 분석 결과를 바탕으로 실제 재생 가능한 음악을 생성한다.
- 사용자가 생성된 음악을 듣고, 다시 생성하거나 일부 방향을 수정할 수 있게 한다.
- 모바일 화면에서 한 손으로 입력, 분석, 생성, 재생까지 완료할 수 있는 경험을 제공한다.

### 사용자 가치
- 독자는 책 속 장면을 청각적으로 체험할 수 있다.
- 독서 모임, 리뷰 콘텐츠, 팬 커뮤니티에서 책의 분위기를 더 생생하게 공유할 수 있다.
- 작가, 출판사, 콘텐츠 제작자는 문학 작품의 홍보용 사운드 콘텐츠를 빠르게 만들 수 있다.

## 3. 대상 사용자

### 핵심 사용자
- 소설, 에세이, 판타지, 로맨스, 추리 등 서사 콘텐츠를 즐겨 읽는 독자
- 책 속 분위기나 장면을 음악으로 상상해보고 싶은 사용자
- 북튜버, 북스타그래머, 독서 모임 운영자 등 독서 콘텐츠 제작자

### 확장 사용자
- 출판사 마케팅 담당자
- 웹소설, 웹툰, 게임 시나리오 작가
- 오디오북, 북트레일러, 팬메이드 콘텐츠 제작자

## 4. 문제 정의

### 사용자가 겪는 문제
- 책 속 음악 묘사는 풍부하지만, 실제 소리로 경험하기 어렵다.
- 음악 생성 도구에 직접 프롬프트를 입력하려 해도 음악 장르, 악기, 템포, 보컬 스타일 등으로 변환하기 어렵다.
- 책의 전체 분위기와 특정 장면의 음악 묘사가 따로 놀 수 있다.
- 가사가 포함된 묘사와 순수한 음악 스타일 묘사가 섞여 있을 때 생성 결과가 불안정하다.

### 해결 방향
서비스가 문학적 표현을 음악 생성에 적합한 구조화된 입력으로 변환한다. 책 단위의 분위기 분석과 문장 단위의 음악 묘사 분석을 결합해, 사용자는 문학적 텍스트만 입력해도 음악을 들을 수 있다.

## 5. 핵심 사용자 시나리오

1. 사용자가 책 제목과 작가명을 입력한다.
2. 사용자가 책 속 음악 묘사 문단을 입력한다.
3. 시스템이 책의 전반적인 분위기를 분석한다.
4. 시스템이 입력 문단에서 음악 스타일, 악기, 템포, 감정, 보컬 여부, 가사 후보를 추출한다.
5. 시스템이 음악 생성용 프롬프트를 구성한다.
6. 시스템이 음악을 생성한다.
7. 사용자가 생성된 음악을 재생한다.
8. 사용자는 결과가 마음에 들지 않으면 “더 어둡게”, “현악기 중심으로”, “가사 없이”, “느리게” 같은 방향으로 다시 생성한다.

## 6. MVP 범위

### 포함 기능

#### 6.1 책 정보 입력
- 사용자는 책 제목과 작가명을 입력할 수 있다.
- 시스템은 입력된 책 정보를 바탕으로 작품의 장르, 정서, 시대감, 주요 분위기를 추론한다.
- MVP에서는 책 전문을 요구하지 않는다.
- 사용자가 책 줄거리나 장면 설명을 추가로 입력할 수 있는 선택 필드를 제공한다.

#### 6.2 음악 묘사 텍스트 입력
- 사용자는 책에서 발췌한 음악 묘사 문장을 입력한다.
- 입력 예:
  - “낡은 피아노에서 느리고 흐릿한 왈츠가 흘러나왔다.”
  - “그녀는 바다를 잊지 말라는 가사를 낮고 쉰 목소리로 불렀다.”
- 텍스트는 직접 타이핑하거나 붙여넣는 방식으로 입력한다.

#### 6.3 음악 스타일과 가사 분리
- 시스템은 입력 텍스트를 다음 항목으로 분리한다.
  - 음악 스타일: 장르, 시대감, 악기, 템포, 리듬, 분위기, 보컬 톤
  - 가사: 명시적 가사, 암시적 가사 주제, 반복구 후보
  - 장면 맥락: 장소, 시간대, 인물의 감정, 서사적 긴장감
- 가사가 명확하지 않을 경우 시스템은 가사 없는 연주곡 생성을 기본값으로 사용한다.
- 사용자는 생성 전 “가사 포함” 또는 “가사 없음”을 선택할 수 있다.

#### 6.4 음악 생성
- 시스템은 책 분위기 분석 결과와 음악 묘사 분석 결과를 결합해 음악 생성 프롬프트를 만든다.
- 생성 결과는 30~90초 길이의 오디오 클립으로 제공한다.
- MVP에서는 1회 생성 시 1~3개의 후보 트랙을 제공한다.
- 각 후보는 제목, 짧은 설명, 생성 기준을 함께 표시한다.

#### 6.5 음악 재생
- 사용자는 웹 플레이어에서 음악을 재생, 일시정지, 다시 듣기 할 수 있다.
- 생성된 트랙의 기본 메타데이터를 확인할 수 있다.
  - 책 제목
  - 작가명
  - 장면/묘사 텍스트
  - 추출된 스타일
  - 가사 포함 여부

#### 6.6 재생성 및 방향 수정
- 사용자는 다음과 같은 간단한 수정 옵션을 선택할 수 있다.
  - 더 밝게
  - 더 어둡게
  - 더 느리게
  - 더 빠르게
  - 보컬 추가
  - 보컬 제거
  - 악기 중심 변경
  - 책 분위기 반영 강도 조절
- 고급 사용자는 직접 수정 지시문을 입력할 수 있다.

### 제외 기능
- 책 전문 자동 수집 또는 무단 분석
- 상업용 음원 배포
- 특정 실제 가수, 밴드, 작곡가의 스타일을 직접 모방하는 기능
- 사용자가 업로드한 긴 오디오를 학습해 유사 음악을 만드는 기능
- 소셜 피드, 팔로우, 댓글 등 커뮤니티 기능

## 7. 주요 기능 요구사항

### FR-1. 책 분위기 분석
- 입력: 책 제목, 작가명, 선택적 줄거리/장면 설명
- 출력:
  - 장르 추정
  - 시대/배경 추정
  - 핵심 정서
  - 음악 생성 시 반영할 분위기 키워드
- 시스템은 책 정보가 모호할 경우 사용자에게 추가 설명 입력을 권장한다.

### FR-2. 음악 묘사 분석
- 입력: 사용자가 입력한 음악 묘사 텍스트
- 출력:
  - 음악 스타일 필드
  - 가사 필드
  - 장면 맥락 필드
  - 불확실성 표시
- 시스템은 분석 결과를 사용자에게 보여주고, 사용자가 수정할 수 있게 한다.

### FR-3. 프롬프트 조합
- 책 분위기와 음악 묘사를 하나의 음악 생성 지시문으로 합성한다.
- 문학적 표현은 음악 생성에 적합한 표현으로 변환한다.
- 예:
  - “쓸쓸한 겨울 저녁” → “slow tempo, sparse piano, soft strings, melancholic mood”
  - “낡은 술집의 흐릿한 노래” → “intimate jazz bar ambience, muted brass, warm tape texture”

### FR-4. 음악 생성
- 사용자는 생성 버튼을 눌러 음악 생성을 시작할 수 있다.
- 생성 중에는 진행 상태를 표시한다.
- 생성 실패 시 재시도 옵션과 실패 사유를 제공한다.

### FR-5. 재생 및 저장
- 사용자는 생성된 음악을 재생할 수 있다.
- 로그인 사용자는 생성 이력을 저장할 수 있다.
- 비로그인 사용자는 현재 세션에서만 결과를 확인할 수 있다.

### FR-6. 재생성
- 사용자는 기존 결과를 바탕으로 방향을 수정해 다시 생성할 수 있다.
- 재생성 요청은 이전 분석 결과와 사용자 수정사항을 함께 사용한다.

## 8. 비기능 요구사항

### 성능
- 음악 묘사 분석 결과는 5초 이내 제공하는 것을 목표로 한다.
- 음악 생성 결과는 60초 이내 첫 후보 제공을 목표로 한다.
- 생성 시간이 길어질 경우 대기 화면과 알림을 제공한다.

### 품질
- 생성된 음악은 사용자가 입력한 분위기와 최소 1개 이상의 명시적 음악 단서를 반영해야 한다.
- 가사 포함 요청 시 가사는 사용자의 텍스트를 그대로 복제하기보다 장면의 주제를 바탕으로 새롭게 생성한다.
- 사용자가 입력한 원문이 짧을수록 시스템은 추론 근거와 불확실성을 명확히 표시한다.

### 안전 및 저작권
- 사용자가 입력한 책 발췌문은 생성 목적에만 사용한다.
- 긴 본문 입력 시 저작권 안내를 표시하고 필요한 최소 범위의 발췌만 입력하도록 유도한다.
- 특정 실존 아티스트, 밴드, 작곡가를 모방하는 요청은 대체 표현으로 변환한다.
- 생성 결과가 기존 음원과 혼동될 수 있는 방식으로 마케팅되지 않도록 안내한다.

### 개인정보
- 비로그인 사용자의 입력과 생성 결과는 세션 종료 후 삭제한다.
- 로그인 사용자의 저장 데이터는 사용자가 직접 삭제할 수 있어야 한다.
- 책 제목, 작가명, 묘사 텍스트, 생성 프롬프트, 결과 오디오는 별도 필드로 관리한다.

## 9. 사용자 경험 요구사항

### 기본 화면 흐름
1. 책 정보 입력
2. 음악 묘사 입력
3. 분석 결과 확인
4. 생성 옵션 선택
5. 음악 생성
6. 재생 및 재생성

### 모바일 UX 기준
- 1차 MVP는 모바일 웹을 기준으로 설계한다.
- 기준 해상도는 390x844 iPhone 계열과 360x800 Android 계열이다.
- 모든 주요 액션 버튼은 엄지로 누르기 쉬운 하단 또는 본문 하단 영역에 배치한다.
- 입력 폼은 단일 컬럼으로 구성하고, 단계별 접힘/펼침을 통해 긴 화면 피로를 줄인다.
- 오디오 플레이어와 재생성 버튼은 생성 후 화면 하단에서 바로 접근 가능해야 한다.
- 가로 스크롤 없이 모든 텍스트와 컨트롤이 표시되어야 한다.

### UX 원칙
- 사용자는 음악 용어를 몰라도 사용할 수 있어야 한다.
- 분석 결과는 전문 용어보다 이해하기 쉬운 한국어로 먼저 보여준다.
- 고급 옵션은 기본 흐름을 방해하지 않도록 접어둔다.
- 생성 전 사용자가 “이런 음악을 만들 예정”이라는 요약을 확인할 수 있게 한다.

## 11. 성공 지표

### MVP 지표
- 음악 생성 완료율
- 첫 생성 후 재생률
- 재생 후 30초 이상 청취율
- 재생성 요청률
- 사용자가 분석 결과를 수정하는 비율
- 생성 결과 만족도

### 정성 지표
- “책의 분위기와 잘 맞는다”는 사용자 피드백
- “내가 상상한 장면과 비슷하다”는 사용자 피드백
- 독서 콘텐츠 제작자가 결과를 공유하고 싶어 하는지 여부

## 12. 리스크 및 대응

### 리스크 1. 책 분위기 추론 오류
- 대응: 사용자가 줄거리/장면 설명을 추가할 수 있게 한다.
- 대응: 분석 결과를 생성 전 수정 가능하게 한다.

### 리스크 2. 음악 묘사와 생성 결과의 불일치
- 대응: 추출된 스타일 요소를 명시적으로 보여준다.
- 대응: 재생성 옵션을 단순하고 빠르게 제공한다.

### 리스크 3. 저작권 민감성
- 대응: 긴 원문 입력을 제한하거나 안내한다.
- 대응: 발췌문 저장 정책을 투명하게 제공한다.
- 대응: 실존 아티스트 모방 요청을 차단하거나 일반적 음악 표현으로 변환한다.

### 리스크 4. 생성 비용 증가
- 대응: 비로그인 사용자의 무료 생성 횟수를 제한한다.
- 대응: 짧은 미리듣기 생성 후 확장 생성하는 구조를 검토한다.

## 13. 출시 범위

### 1차 MVP
- 책 제목/작가 입력
- 음악 묘사 텍스트 입력
- 스타일/가사 분리
- 분석 결과 확인 및 수정
- 30~90초 음악 생성
- 웹 플레이어 재생
- 간단한 재생성 옵션
- 모바일 360px 너비에서도 깨지지 않는 단일 컬럼 UI

### 2차 확장
- 생성 결과 저장 및 라이브러리
- 독서 노트와 음악 연결
- 장면별 플레이리스트 생성
- 오디오북 또는 북트레일러용 내보내기
- 사용자가 직접 만든 책별 사운드 컬렉션 공유

## 14. 오픈 질문

- 책 분위기 분석은 외부 도서 데이터베이스를 사용할 것인가, 사용자가 입력한 정보만 사용할 것인가?
- 생성 음악의 기본 길이는 몇 초가 적절한가?
- 가사를 생성할 때 원문의 문장을 어느 정도까지 반영할 수 있게 할 것인가?
- 생성 결과를 다운로드할 수 있게 할 것인가, 스트리밍 재생만 허용할 것인가?
- 상업적 사용을 허용할 경우 라이선스 정책을 어떻게 설계할 것인가?

## 15. MVP 기준 완료 정의

- 사용자가 책 제목, 작가, 음악 묘사 텍스트를 입력할 수 있다.
- 시스템이 책 분위기와 음악 묘사를 구조화해 보여준다.
- 시스템이 음악 스타일과 가사를 분리해 표시한다.
- 사용자가 생성 옵션을 확인하고 음악 생성을 실행할 수 있다.
- 생성된 음악을 웹에서 재생할 수 있다.
- 사용자가 최소 1가지 방향 수정 후 재생성할 수 있다.
- 저작권 및 실존 아티스트 모방 관련 기본 안전장치가 적용되어 있다.
